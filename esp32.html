Weather-Responsive
LED System.

A hands-on ESP32 and addressable LED lighting project, that automatically translates live weather conditions into animated light effects. Python fetches current conditions from Open-Meteo and streams RGB frames over Wi-Fi to WLED on an ESP32.

Project overview

Personal electronics project

Python · ESP32 / WLED · Open-Meteo · UDP

15 × 4 LED matrix · 25 FPS · 3-minute weather polling

How it works

A Python controller requests current weather from the Open-Meteo API, including weather code, temperature, precipitation, and day/night status. Weather codes select an animation, and a custom RGB renderer sends complete frames to WLED over UDP realtime mode.

Technical implementation

The supplied implementation targets a 15 × 4, serpentine-wired LED matrix (60 LEDs), runs animations at 25 frames per second, and refreshes weather data every three minutes. Effects cover clear skies, partial cloud, overcast, fog, rain, snow, and thunderstorms. Dry nighttime conditions trigger independently twinkling stars.

Rain and snow use moving particles; storms combine rain with procedurally generated, branching lightning flashes. The controller preserves the current effect if a weather request fails and retries after approximately one minute.

System architecture

Live weather API → Python weather classification → RGB animation generation → UDP/Wi-Fi → ESP32 running WLED → addressable LED matrix
